## Local

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run deploy
```

Publishes the production build to the `gh-pages` branch.

## Stack

React, React Router (hash routes), GitHub Pages.
